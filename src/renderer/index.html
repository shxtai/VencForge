Добро пожаловать в VencForge
Собери Vencord со своими плагинами и установи на Discord — с OpenAsar и без ограничений.
Статус
Клиенты
⚠ Запущены: . Для установки патча клиенты нужно закрыть — VencForge предложит это сам.
Прочее
VencForge патчит Discord так же, как официальный инсталлер Vencord: оригинальный app.asar сохраняется как app-original.asar, а в _app.asar живёт OpenAsar (если включён). «Починить» нужно после крупных обновлений Discord — или просто нажми «Обновить и установить всё». Vesktop VencForge не трогает.
Добавить плагин
Поддерживаются плагины в формате Vencord (userplugins): папка или репозиторий с index.ts/tsx/js/jsx (в корне или одной подпапке) либо одиночный файл с export default.
По умолчанию подключён P2PStream (git)

Как это работает
VencForge клонирует Vencord в %APPDATA%\VencForge\workspace, кладёт плагины в src/userplugins, запускает pnpm install + build (Node/pnpm подберёт сам: системные или скачает) и копирует результат в %APPDATA%\VencForge\dist. Затем патчит Discord (+ OpenAsar, если включён). При каждом обновлении исходников плагины пересоздаются из списка — поэтому они не теряются.
Поведение
Автообновление по расписанию
Создаётся задача Windows «VencForge Auto-Update». Тихий пропуск: если клиенты запущены — патч отложится; если ничего не изменилось — сборка не повторяется.
GitHub-токен (необязательно)
Нужен только для приватных репозиториев плагинов или при упоре в лимиты GitHub. Токен хранится локально в %APPDATA%\VencForge\state.json.
